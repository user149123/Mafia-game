# 🕵️ 마피아 역할 배정 & 진행 웹앱

사회자 없이 오프라인에서 마피아 게임을 할 수 있도록 만든 순수 HTML/CSS/JS 웹앱입니다.
서버나 빌드 과정 없이 `index.html` 파일 하나로 동작하며, GitHub Pages로 바로 배포할 수 있습니다.

## 기능

- 전체 인원 수와 역할별(마피아 / 경찰 / 의사 / 스파이) 인원수를 자유롭게 설정
- 각자 순서대로 카드를 눌러 자신의 역할을 확인하고 이름 입력 (다른 사람에게 안 보이게 잠금)
- 전원 확인 후 카드가 번호 대신 이름으로 표시됨
- **낮 투표(선거)**: 카드를 눌러 투표하고 최다 득표자를 처형 (동표면 무산, 살아있는 사람만 참여)
- **밤 진행**: 마피아 / 경찰 / 의사 / 스파이 / 시민 모드를 눌러 각자 턴에 행동
  - 마피아: 제거할 대상 선택
  - 의사: 치료할 대상 선택
  - 경찰: 대상이 마피아인지 확인
  - 스파이: 대상의 정확한 직업 확인
  - 시민: 행동 없음 (한눈에 보이도록 동일한 화면 구성)
- 아침에 밤 사이 결과(사망/치료) 자동 계산
- 마피아 팀(마피아+스파이) 전멸 시 시민 승리, 시민 팀 전멸 시 마피아 승리 자동 판정

## 사용 방법

1. 이 저장소를 GitHub Pages로 배포하거나, `index.html`을 다운로드해 브라우저로 바로 엽니다.
2. 인원수와 역할별 인원을 설정하고 "게임 시작"을 누릅니다.
3. 폰을 돌려가며 각자 카드를 눌러 역할과 이름을 확인합니다.
4. "낮 시작하기"를 눌러 게임을 진행합니다.

## GitHub Pages로 배포하기

1. 이 폴더(`index.html`, `README.md`)를 새 GitHub 저장소에 업로드합니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Branch**를 `main` (또는 사용 중인 브랜치), 폴더를 `/ (root)`로 설정하고 저장합니다.
4. 잠시 후 `https://<사용자이름>.github.io/<저장소이름>/` 주소로 접속하면 바로 게임을 사용할 수 있습니다.

## 기술 스택

순수 HTML + CSS + JavaScript (프레임워크·빌드 도구 없음). 모바일 브라우저에 최적화되어 있습니다.
